# Widget v0.2.1

恢复历史时带回关联笔记正文，并调整默认侧栏和历史入口。

## 更新内容

- 左侧人设栏在没有保存偏好时默认收起；展开、收起仍会保存用户偏好。
- 历史记录同时恢复笔记正文和评论，切换记录时清空之前的筛选。未保存原文的旧记录会清空正文输入并提示，不把摘要冒充原文；加载失败时保留当前结果并提示错误。
- 「生成历史」按钮移到「运行控制」标题后方。
- 全屏切换与人设、历史加载分别执行；已处于目标显示模式时跳过重复请求。
- 首次连接主动上报尺寸；新增隐藏窗口、全屏响应延迟、同尺寸重开、历史正文和独立浏览器模式回归。

## Codex 侧窗白屏的已验证绕过方式

在 Codex 26.831.21537 中，侧窗可能在打开或重开后保持空白，调整窗口大小或发送消息后才显示。

打开 **Codex 设置 → 通用 → 外观 → 减少动态效果（Reduce motion）→ 开（On）**，即关闭动态效果。真实客户端测试确认，此后侧窗立即显示，不需要调整尺寸或发送消息。

这是 Codex 宿主动画问题的绕过方式，**不表示插件已经修复 Codex 的外层显示逻辑**。浏览器模拟宿主回归也不能替代实际 Codex 客户端验收。

## 升级

```bash
codex plugin marketplace upgrade xhs-simulator-github
codex plugin add xhs-simulator@xhs-simulator-github
```

完全退出并重新启动 Codex，再打开模拟器。展开左侧人设栏可确认标题显示 **v0.2.1**。

现有模拟历史无需迁移，不要删除 `~/.xhs-simulator/`。本版未改变人设、模拟协议或 MCP 结果存储结构。

## 验证

- 构建产物一致性、Widget 内联脚本、MCP 协议、无依赖冷安装启动和 Vue TypeScript。
- 浏览器回归：严格沙箱、允许同源、初始隐藏及全屏响应延迟、连续三次同尺寸重开、独立浏览器数据通道。
- 默认收起、完整正文恢复、旧记录缺少正文提示和模拟消息交接。
- 保留 v0.2.0 的复制及评论楼层能力。
