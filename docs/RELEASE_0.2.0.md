# Widget v0.2.0

同步独立版 v0.5.0 的界面与参与规则，保持无账号、无额外模型 API、本地存储。

## 更新内容

- 完整展示所有深度的评论，修复筛选深层回复时因父评论未选中而漏显示、漏复制的问题。
- 声明 MCP Apps 资源的剪贴板写入权限；自动复制失败回退旧式复制，再失败则打开可全选的文本窗口。
- 随时可点「查看复制文本」手动复制；新增可选的表格格式，将每条评论整理为一行，保留序号与楼层标签。
- 复制筛选结果和复制全部的按钮名称区分；复制只在本地执行，不发送 Codex 消息。
- 通用人设扩充到 60 人；路人注入最大 40 人，默认 5 人。
- 增加生成首评前的确定性参与校准；常驻人设保留，普通路人条件评论保留概率为 45%，未保留者降为点赞。保存时不二次削减。
- 更新多轮参与协议：没有全程一次限制；允许未发言者后续加入，首评后的第一轮不施加连续发言疲劳，之后参考上一轮发言情况。
- 保留现有独立浏览器 / Codex Widget 双模式，不改独立版的 Python 业务代码。插件用户无需启动本地网站。
- 样式构建只扫描前端源码，避免把本地笔记或测试文档里的字符串误打包为样式。

## 升级

```bash
codex plugin marketplace upgrade xhs-simulator-github
codex plugin add xhs-simulator@xhs-simulator-github
```

重新启动 Codex 并新建任务，输入「打开小红书评论模拟器」。标题应显示 **v0.2.0**。本机已有模拟结果不需要迁移，不要删除 `~/.xhs-simulator/`。

## 验证范围

- 构建产物一致性、Widget 内联脚本、MCP 工具、无依赖冷安装启动、Vue TypeScript、插件与 Skill 格式检查。
- 64 位参与人设（24 目标 + 40 路人）、seed=0、重复请求、首评一致性、重复发言与后续加入回归。
- 25 个 seed 共 1000 次合格路人校准，实际保留 483 次（概率不是固定人数配额）。
- 实际发布 HTML 的浏览器回归：18 条完整显示/粘贴、深层筛选、表格格式；包含允许、禁止剪贴板权限、手动复制、严格沙箱及独立浏览器五种场景。

这些浏览器测试使用本地模拟宿主与虚构数据，不等于在每个版本的 Codex 客户端上实测。宿主可以拒绝自动剪贴板权限，此时使用手动复制入口。模拟/挑选消息的宿主确认机制没有被取消。
